# .agents Skill Monitor

## Русский

Откройте `index.html` в браузере. Установка зависимостей не нужна.
Интерфейс доступен на русском, английском и упрощённом китайском.

Клиент показывает снимок настоящего каталога проекта: компоненты, явно
указанные зависимости и рекомендуемые навыки. Источник и время снимка видны
в интерфейсе. Это не список фактически загруженных навыков Codex или Claude.
Перечитывание снимка в интерфейсе не сканирует диск и не обновляет его дату.

В этой версии работают поиск, схема связей, просмотр записей и подготовка
черновика задания CEO. Черновик остаётся в текущей вкладке, не отправляется
и не выполняется. Живой мониторинг, сканирование уязвимостей и запуск заданий
не подключены. Отсутствие замечаний к каталогу не подтверждает безопасность
файлов и инструкций.

## English

Open `index.html` in a browser. No dependency installation is required.
The interface supports Russian, English and Simplified Chinese.

The client displays a snapshot of the real project catalog: components,
declared dependencies and recommended skills. Its source and capture time
are shown in the interface. It is not an inventory of skills actually loaded
by Codex or Claude. Reloading the snapshot in the interface does not scan
the disk or change the capture time.

This version supports search, relationship diagrams, record details and CEO
task drafts. A draft stays in the current tab and is not sent or executed.
Live monitoring, vulnerability scanning and task execution are not connected.
A catalog with no diagnostics does not establish the safety of its files
or instructions.

## 简体中文

在浏览器中打开 `index.html`, 无需安装依赖。
界面支持俄语、英语和简体中文。

客户端显示真实项目目录的快照, 包括组件、声明的依赖关系和推荐技能。
界面中会显示快照来源和采集时间。这不是 Codex 或 Claude 实际加载的技能清单。
在界面中重新读取快照不会扫描磁盘, 也不会更改采集时间。

此版本支持搜索、关联关系图、记录详情和 CEO 任务草稿。
草稿仅保留在当前标签页中, 不会发送或执行。
实时监控、漏洞扫描和任务执行尚未接入。
目录诊断未发现问题, 并不代表其文件或指令安全。
