Changes and remaining checks

Mac client

Local inspection without changing files

Read supported metadata in selected folders, starting with ~/.agents. Review a descriptor without changing files, then optionally send its preview to a model through a loopback server. This website does not read your files.

Available on Mac

Inspect components without running them

Findings in one place

Open all components with findings in one action. Counts, severity symbols and severity text help you choose what to review. Read notices remain separate.

Choose folders and follow links

Read supported skills, agents, MCP and RAG metadata in selected folders. Links show declared references and index matches, not verified runtime connections.

Review one descriptor

Inspect suspected signals with file evidence and line numbers where available, SHA-256 and coverage limits. Helper code and RAG contents are outside the review. Findings are not a safety verdict.

Optional local AI

Check a loopback server connection, choose a model and inspect the redacted preview. Each send needs a new explicit click. Redaction may miss secrets; the server may store or forward prompts.

Track changes during a session

Enable refresh every 30 seconds and review up to 500 journal events. Manual copy-and-paste folder suggestions remain separate from model connections and unchecked until you choose them.

Keep control of your files

No automatic fixes, component execution, plugin installation or telemetry. Folders, language, settings, journal and audit responses stay in memory until quit. Changing folders resets the journal.

What has been checked

739 assertions, 11 real-filesystem scenarios with no skips, and a packaging test passed for each architecture: arm64 natively and x86_64 through Rosetta on Apple Silicon. The bundled app completed GET and POST against a synthetic loopback fixture; real model inference was not tested. Clean-Mac launch, physical Intel hardware, macOS 13, the full minimum window, keyboard-only use, VoiceOver and human usability remain unverified. The unconnected shared interface retains 21 checks.
