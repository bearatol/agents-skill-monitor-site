Changes and remaining checks

Mac client

Local inspection without changing files

The app reads supported metadata in selected folders, starting with ~/.agents. It does not run components or make network requests. Folders, language and the journal last only until you quit. This website does not read files.

Available on Mac

Inspect components without running them

Choose your folders

~/.agents is selected by default. Add other folders as needed. The app reads SKILL.md files, agent metadata and supported MCP and RAG configurations. Other formats may not appear in the list.

Declared links

See the dependencies and sources declared in metadata and which references match indexed components. This does not establish working connections.

Findings with explanations

Passive metadata checks identify patterns for manual review, including informational advisories. They are not antivirus protection or a source-code audit.

Changes while the app is open

Optionally refresh every 30 seconds while the app is open. Folder choices, language and the journal stay in memory only until you quit. Changing folders resets history.

Manual exchange with your AI

Copy a request, send it to your AI, then paste its response with suggested folders. No model is connected. Suggestions are added only after you choose them.

Local reading

The Mac client makes no network requests, collects no telemetry, changes no files and runs no packages. APM ownership stays unchanged; APM installation and updates are not connected.

What has been checked

The Mac client passed 503 assertions and 11 real-filesystem scenarios on each architecture: native arm64 and x86_64 via Rosetta on Apple Silicon, with no skips. This does not verify operation on Intel hardware or macOS 13. The shared interface passed 21 checks; independent product review covered source and a synthetic DOM. Real-browser checks, clean-Mac launch, VoiceOver and the minimum 1040×650 window remain unverified. No user study has been conducted.
